# City-Hour Air Quality Analysis

Hourly air-quality analysis across Indian cities: data cleaning, exploratory analysis, AQI regression and classification, short-term forecasting, and event/behaviour studies (Diwali, COVID-19 lockdown, PCA, city comparison).

Two notebooks make up the project:

| Notebook | Purpose |
|---|---|
| `notebooks/city_hour_analysis.ipynb` | Core pipeline: cleaning, EDA, feature engineering, regression and classification models |
| `notebooks/city_hour_extension.ipynb` | Extensions: forecasting, Diwali effect, lockdown impact, PCA, city comparison |

Both notebooks are already executed, so outputs are visible directly on GitHub.

## Part 1: Core analysis

**Pipeline**

1. **Clean:** parse dates, remove duplicates, sort, drop empty rows, drop Xylene (61% missing).
2. **Hourly EDA.**
3. **Time features:** hour, rush-hour, night, weekend, season, cyclic hour encoding.
4. **Impute** predictors using train-only city + month medians (avoids leakage).
5. **Split:** train 2015-2019, test 2020.
6. **Models:** Linear/Logistic baseline, Decision Tree, Random Forest.

**Results (test set = 2020)**

| Task | Best model | Key result |
|---|---|---|
| Regression | Random Forest | MAE 33.2, RMSE 58.8, R² 0.578 (baseline R² 0.517) |
| Classification | Random Forest | Accuracy 0.667, macro-F1 0.548 (baseline 0.643 / 0.530) |

## Part 2: Extensions

| Analysis | Key finding |
|---|---|
| **Next-hour forecast** (test 2020) | Persistence R² 0.968 / Linear 0.973 / **Random Forest 0.976** (RMSE 14.1 vs 16.2). RF beats persistence on RMSE but not on MAE (2.98 vs 2.73), i.e. it helps on large swings, not typical hours. |
| **Next-day (24h-ahead) forecast** | Persistence R² 0.608 / Linear 0.630 / **Random Forest 0.632**. Only a small gain over persistence: next-day AQI is hard to predict from past values alone (no weather data). |
| **Diwali effect** | Delhi peak hourly PM2.5 is 2.9x-8.8x the pre-Diwali baseline (peak 515-798 µg/m³); across all cities 3.8x-7.4x. The spike appears within about a day of Diwali night. |
| **COVID lockdown** (25 Mar-30 Jun 2020 vs 2018-19) | Median change across cities: PM2.5 -41%, NO2 -43%, CO -28%. Every city with data shows a PM2.5 fall (-7% to -57%). |
| **PCA vs raw pollutants** | Raw (11 pollutants) R² 0.598; PCA with 9 components (90% variance) 0.389; PCA with 4 components 0.415. PCA hurt: AQI depends on the *specific* dominant pollutant, which PCA blends away. Raw features / feature importance are preferred. |
| **City comparison** | Mean hourly AQI: Ahmedabad 455 (see caveat), Delhi 260, Lucknow 218, Kolkata 141 ... Bengaluru 94. |

## Caveats

- **Ahmedabad data quality:** hourly AQI is unusually high (median 312, 5.5% of readings above 1000), likely a data/sensor quirk in this dataset. This is why `city_Ahmedabad` appears as an important feature in the core models, and it inflates its rank in the city comparison.
- **Lockdown comparison is observational:** weather also differs between years, so the changes cannot be attributed to lockdown alone.
- **Diwali baselines** use a single manually entered list of Diwali dates.
- **Forecasting has no weather inputs,** which limits next-day accuracy.

## Reproducing

1. Place `city_hour.csv` in `data/raw/`.

3. Run `notebooks/city_hour_extension.ipynb` to produce the extension results and regenerate `data/processed/city_hour.db`.
