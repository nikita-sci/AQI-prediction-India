# City-Hour (hourly) analysis

Notebook: `notebooks/city_hour_analysis.ipynb` (already executed; outputs visible on GitHub).

**Place files like this in the repo:**
- `data/raw/city_hour.csv` (original file; ~65 MB, fine for GitHub's 100 MB limit, or keep it git-ignored)
- `data/processed/city_hour_clean.csv.gz` (cleaned + feature-engineered, 19 MB)
- `outputs/figures/city_hour/*.png`, `outputs/results/city_hour_*.csv`

**Pipeline:** clean (dates, duplicates, sort, drop empty rows, drop Xylene 61% missing) -> hourly EDA -> time features
(hour, rush-hour, night, weekend, season, cyclic hour) -> impute predictors with train-only city+month medians ->
train 2015-2019 / test 2020 -> Linear/Logistic baseline, Decision Tree, Random Forest.

| Task | Best model | Key result (test = 2020) |
|---|---|---|
| Regression | Random Forest | MAE 33.2, RMSE 58.8, R² 0.578 (baseline R² 0.517) |
| Classification | Random Forest | Accuracy 0.667, macro-F1 0.548 (baseline 0.643 / 0.530) |

# City-Hour extension results (`notebooks/city_hour_extension.ipynb`)

| Analysis | Key finding (all numbers from the executed notebook) |
|---|---|
| **Next-hour forecast** (test 2020) | Persistence R² 0.968 / Linear 0.973 / **Random Forest 0.976** (RMSE 14.1 vs 16.2). RF beats persistence on RMSE but not on MAE (2.98 vs 2.73), i.e. it helps on large swings, not typical hours. |
| **Next-day (24h-ahead) forecast** | Persistence R² 0.608 / Linear 0.630 / **Random Forest 0.632**. Only a small gain over persistence: next-day AQI is hard to predict from the past alone (no weather data). |
| **Diwali effect** | Delhi peak hourly PM2.5 is 2.9x-8.8x the pre-Diwali baseline (peak 515-798 µg/m³); across all cities 3.8x-7.4x. Spike appears within about a day of Diwali night. |
| **COVID lockdown** (25 Mar-30 Jun 2020 vs 2018-19) | Median change across cities: PM2.5 -41%, NO2 -43%, CO -28%; every city with data shows a PM2.5 fall (-7% to -57%). |
| **PCA vs raw pollutants** | Raw (11 pollutants) R² 0.598; PCA 9 comps (90% variance) 0.389; PCA 4 comps 0.415. PCA hurt: AQI depends on the *specific* dominant pollutant, which PCA blends away. Raw features / feature importance are preferred. |
| **City comparison** | Mean hourly AQI: Ahmedabad 455 (see caveat), Delhi 260, Lucknow 218, Kolkata 141 ... Bengaluru 94. |

**Caveats (state these in the report):** Ahmedabad's hourly AQI is unusually high (median 312, 5.5% of readings above 1000), likely a data/sensor quirk in this dataset, which is why `city_Ahmedabad` appears as an important feature earlier. Lockdown comparison is observational (weather also differs by year). Diwali baseline comparisons use one date list entered manually.
